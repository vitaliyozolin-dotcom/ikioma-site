# ИКИОМА · ВЕЛА

Русскоязычный сайт проекта ВЕЛА. Производственный домен — [ikioma.ru](https://ikioma.ru/). Основная ветка подключена к Timeweb. На текущем этапе статус выпуска указан в `PROJECT_PASSPORT.yaml`.

## Локальная проверка

Node.js от 22.13.

```bash
npm ci
npm test
npm run lint
npx tsc --noEmit
npm run dev
```

`npm run build:timeweb` проверяет каталог и экспортирует статические страницы в `timeweb-dist`. Отдельно проверяются рекламные маршруты и документы. Не открывайте экспорт через `file://`. Для локального просмотра раздайте его HTTP-сервером.

## Цены, материалы и тексты

Откройте `scripts/vela-catalog-editor.html` в браузере и загрузите `public/vela/catalog.json`. Редактор позволяет менять цены и позиции, характеристики, фотографии, описание, гарантию и параметры сценариев. Новые фотографии добавляйте в `public/vela`, затем указывайте их адрес и подпись объекта. Для изменения нужна новая версия и дата вступления в силу. Экспорт из редактора заменяет `public/vela/catalog.json` в ветке проверки. История редакций доступна в Git. Сохранённые у покупателей расчёты и принятые заявки содержат копию использованных цен.

Планировку обновляйте только по утверждённому PDF. `scripts/export-vela-plan.py` переносит в SVG векторные контуры. Для проверенной новой планировки дополнительно сверьте координаты подсветки и схематичной мебели в `components/VelaPlan.tsx`.

## Заявки

Единая форма использует действующий приёмник СтройОС `/api/public/leads`. Новая версия передаёт идентификатор запроса, версию каталога, выбранные работы, согласие и источник. Для передачи ипотечного сценария нужна отдельная отметка в форме. Приёмник рассчитывает сумму по своему экземпляру опубликованного каталога, сохраняет заявку в `ikioma-sales` и возвращает идентификатор. Повтор отправки с тем же идентификатором возвращает существующую запись. На сторонних доменах CORS закрыт.

Для публичного запуска сначала выпустить совместимый приёмник в репозитории `vitaliyozolin-dotcom/stroi_os`. Затем выпустить статический сайт из `main` на Timeweb. Проверить HTTPS, каталог, страницу, документы и сквозную заявку с пометкой TEST. Сверить её по идентификатору в разделе «Маркетинг и воронка» и проверить повтор. Ошибки приёмника записываются в журнал СтройОС с идентификатором запроса. При настроенном Telegram выводится уведомление без контактов клиента. Откат выполняется обычным revert и выпуском предыдущего совместимого состояния.

## Аналитика

Код публикует события `ikioma:goal`. После подтверждения счётчика и условий подключения Яндекс Метрики используйте `window.__IKIOMA_YM_ID` и передавайте события через `reachGoal`. Включите цели `calculator_start`, `calculator_complete`, `service_select`, `mortgage_calculator_open`, `quote_pdf`, `contact_click`, `lead_open`, `lead_success`. Последняя цель срабатывает после получения идентификатора заявки. Контакты и параметры ипотечного расчёта в цели не передаются. Рекламные адреса для ВЕЛА имеют общий canonical и дают разные входы в один проект.
