# ИКИОМА

Официальный сайт строительной компании ИКИОМА: современный дом АРО 120,
комплектации, этапы строительства, контроль, финансирование и калькулятор.

## Запуск локально

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

## Проверка

```bash
npm test
```

## Сборка для Timeweb

```bash
npm ci
npm run build:timeweb
```

Готовый статический сайт создаётся в каталоге `timeweb-dist`.

Настройки приложения в Timeweb:

- ветка: `main`;
- команда установки: `npm ci`;
- команда сборки: `npm run build:timeweb`;
- каталог публикации: `timeweb-dist`;
- домен: `ikioma.ru`;
- автодеплой: включён.

## Источники истины

- код и история изменений: этот репозиторий;
- основная ветка: `main`;
- рабочий домен: `https://ikioma.ru`;
- текущая контрольная версия до переноса: `https://ikioma-homes.ozolin.chatgpt.site`.

Текущий статус и маршрут проекта хранятся в `PROJECT_PASSPORT.yaml`.
